# 别慌，慢慢来 · 一个不用慌的角落

`www.sushine.xyz` 的站点源码。纯静态、零依赖、零第三方请求，可直接部署到 Cloudflare Pages。

## 定位：从「线上寺庙」到「虚拟解压环境」

灵感来自两个真实需求：

1. **韩国 Templestay 的爆点**——年轻人真正需要的是「被允许什么都不做」：慢、留白、安静、有个不必给谁看的地方说句话。
2. **《慌啥子嘛》的情绪共鸣**——2026 年 11 月赵本山翻唱的川渝方言歌刷屏，核心是「不说教的长辈式松弛感」。但这首歌的**歌名与歌词受《著作权法》保护**，已有商家因未经授权把歌词印在车贴上被律师指侵权。

因此本页的处理是：**只借「别慌、慢慢来」这个方言情绪母题，文案、画面、代码全部原创**，把韩国寺庙的「静」改造成中国年轻人能接受的「虚拟解压环境」。

## 「本地即焚 / 零请求」是技术事实，不是文案

1. `quiet.js` 不含任何网络请求（fetch/XHR/beacon）或持久化存储（localStorage/cookie）API——只操作 DOM，写下的字仅在 `textarea.value`，淡出后清空。
2. `_headers` 设置 `connect-src 'none'` 与 `form-action 'none'`，浏览器层面硬性禁止本页主动发起网络请求或表单提交；`script-src 'self'` 禁止第三方脚本。
3. `Referrer-Policy: no-referrer`，外链不携带来源信息。
4. 全站无外链图片、字体、CDN、统计脚本；SVG 场景内联绘制；音效用 Web Audio 合成。
5. 页面中的外部链接（品牌站、合作邮箱）需用户主动点击才会打开，不算本站主动请求。

- Framework preset：**None**
- Build command：**留空**
