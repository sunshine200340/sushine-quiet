# 停云 · 一页安静

`www.sushine.xyz` 的站点源码。一个纯静态、零依赖、零第三方请求的中文页面。

## 为什么是「停云」，而不是「线上寺庙」

灵感来自韩国 Templestay（寺院寄宿）近年爆火的「多巴胺戒断 / Do nothing but relax」——年轻人真正需要的是**被允许什么都不做**：慢、留白、安静、有一个不必给谁看的地方说句话。

但国内个人网站不能照搬宗教外壳。依据《互联网宗教信息服务管理办法》第十五至十九条，许可证申请人须为境内依法设立的法人或非法人组织并经省级宗教事务部门审批，个人主体无法取得；第十七条禁止个人在互联网上组织开展宗教活动、发布讲经讲道内容或直播录播拜佛、烧香、诵经、礼拜等仪式；第十八条禁止设立宗教活动场所；第十九条禁止以宗教名义募捐。该办法对「互联网宗教信息服务」的界定还明确包含**宗教知识、宗教文化**类信息。

因此本页的处理是：**完整保留静、慢、留白与倾诉体验，剥除全部宗教与医疗外壳**。

- 「停云」出自陶渊明《停云》，纯文学意象，无宗教属性；视觉只用远山、云、窗棂、竹影、宣纸、墨，不用寺庙、造像、香炉、钟、木鱼、念珠、莲花等符号。
- 用「今日一句旧诗」替代抽签与签文：**按日期确定性呈现**，不随机、不预测、不解读，注明出处，全部取自有公有领域古籍。
- 用「停一停」替代禅修与冥想：只是呼吸圆环与三分钟计时，文案只用「慢慢吸 / 停一下 / 慢慢呼」，含「不舒服就随时停」提示。
- 用「放在这里」替代祈愿与云端树洞：**本地即焚**。
- 用「此刻可做的小事」替代黄历宜忌：只是几件低成本生活动作，明确写「不是建议，也不保证什么」。

## 「本地即焚」不是文案，是技术事实

1. `quiet.js` 中不出现任何网络请求或持久化存储 API——只操作 DOM，写下的字仅存在于 `textarea.value`，淡出后即清空。
2. `_headers` 设置 `connect-src 'none'` 与 `form-action 'none'`，由浏览器**硬性禁止本页发起任何网络请求或表单提交**；`script-src 'self'` 禁止第三方脚本。
3. `Referrer-Policy: no-referrer`，外链不携带来源信息。
4. 全站无外链图片、字体、CDN、统计脚本；SVG 场景内联绘制。

可在浏览器开发者工具的 Network 面板复核：除 `index.html` / `style.css` / `quiet.js` 三个同源文档外，不应出现任何请求。
