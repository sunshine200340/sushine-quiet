# 向阳而生 · 慢慢变好 | sushine.xyz

`www.sushine.xyz` 的站点源码。纯静态、零依赖、零第三方请求，可直接部署到 Cloudflare Pages。

品牌名「向阳而生」呼应域名 sunshine / sushine；主标题「向阳而生，慢慢变好。」是针对首页视觉稿（Calm 式大标题）的原创改写。「别慌，慢慢来」保留为情绪副线，约定俗成的「慌啥子嘛」只作口语母题，不引用任何歌曲歌词或旋律。小报童入口始终保留在「支持本站」区。

## 定位：从「线上寺庙」到「虚拟解压环境」

灵感来自两个真实需求：

1. **韩国 Templestay 的爆点**——年轻人真正需要的是「被允许什么都不做」：慢、留白、安静、有个不必给谁看的地方说句话。
2. **《慌啥子嘛》的情绪共鸣**——2026 年 11 月赵本山翻唱的川渝方言歌刷屏，核心是「不说教的长辈式松弛感」。但这首歌的**歌名与歌词受《著作权法》保护**，已有商家因未经授权把歌词印在车贴上被律师指侵权。

因此本页的处理是：**只借「别慌、慢慢来」这个方言情绪母题，文案、画面、代码全部原创**，把韩国寺庙的「静」改造成中国年轻人能接受的「虚拟解压环境」。

## 信息架构（借鉴 Calm 的结构骨架，内容全原创）

页面按 Calm 的「需求分区 → 内容库 → 免费入门 → 真实信任 → 分类 FAQ → 轻转化」骨架组织，但不照搬其付费订阅、名人代言与音频库：

1. **顶栏**：品牌 + 分区导航（少点慌 / 睡得着 / 慢慢活 / 常见问题）+ 免费入口 + 中英切换 + 当日日期。
2. **首屏**：「慌啥子嘛 → 别慌，慢慢来 → 你不是一个人着急」的情绪钩子，两个行动号召，隐私脚注。
3. **三大需求分区**（对应 Calm 的 Stress less / Sleep more / Live mindfully）：每区 3 张卡片，链接到下方对应模块。
4. **内容模块**：情绪签到 → 空境 → 压力释放馆 → 呼吸 → 即焚书写 → 小事轮换。
5. **数据说明**：Calm 式社会证明的合规替代——不编造用户数与五星，只承诺 0 账号 / 0 Cookie / 0 请求 / 0 广告。
6. **求助 + 支持**：热线护栏 + 三个合规变现出口（小报童 / 知识星球 / 合作邮箱）。
7. **分类 FAQ**：关于本页 / 隐私 / 边界 / 版权备案，把合规边界讲在明处。

## 中英双语

页面右上角「中 / EN」切换整站语言，含所有静态文案、动态生成内容（签到回复、空境说明、呼吸词、计时器、小事、日期）与文档标题、描述。

- 字典集中在 `i18n.js` 的 `DICT`（中文原文 → English），约 186 条。
- 切换只改当前页文本节点与属性，**不写 Cookie / localStorage / sessionStorage**；刷新后回到中文——与零存储承诺一致。
- 英文排版在 `style.css` 用 `html[lang="en"]` 单独适配（西文无需字间距、行高收紧）。
- 新增文案须同步在 `DICT` 补一条；动态文案在 `quiet.js` 中用 `T('中文原文')` 包裹。

## 「本地即焚 / 零请求」是技术事实，不是文案

1. `quiet.js` 不含任何网络请求（fetch/XHR/beacon）或持久化存储（localStorage/cookie）API——只操作 DOM，写下的字仅在 `textarea.value`，淡出后清空。
2. `_headers` 设置 `connect-src 'none'` 与 `form-action 'none'`，浏览器层面硬性禁止本页主动发起网络请求或表单提交；`script-src 'self'` 禁止第三方脚本。
3. `Referrer-Policy: no-referrer`，外链不携带来源信息。
4. 全站无外链图片、字体、CDN、统计脚本；SVG 场景内联绘制；音效用 Web Audio 合成。
5. 页面中的外部链接（品牌站、合作邮箱）需用户主动点击才会打开，不算本站主动请求。
